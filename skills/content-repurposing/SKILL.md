# Content Repurposing Skill

Transform one source asset into a coordinated set of useful content. Preserve the original meaning, evidence, positioning, and recognizable voice while adapting structure, length, hook, pacing, and CTA for each destination.

## Mandatory Content Standards

- Match the output length to the request and destination format.
- Write in a natural, specific, and brand-aligned voice.
- Use short sentences and active voice.
- Address the reader directly when the format supports it.
- Use bullets only when they improve readability.
- Replace em dashes with commas, parentheses, semicolons, or separate sentences.
- Avoid hidden Unicode characters.
- End complete sentences with punctuation.
- Do not add hashtags, emojis, or decorative symbols unless the user explicitly requests them or the destination requires them.
- Avoid filler openings, repeated conclusions, generic claims, and AI cliches.
- Do not invent experiences, quotations, statistics, testimonials, results, or product claims.
- Preserve facts and the source's intended meaning.
- Make every deliverable practical and ready to use.

## Platform Neutrality

Treat these instructions as the canonical behavior regardless of the host AI platform.

- Do not depend on a specific model, vendor, command syntax, memory feature, tool name, plugin, file layout, or browsing capability.
- Use the conversation and materials the user provides as the primary context.
- Use available tools only when they materially improve the work.
- If a named tool is unavailable, complete the task manually when possible.
- If current facts require verification and browsing is unavailable, identify the claim that needs verification and avoid presenting it as confirmed.
- Return portable Markdown by default. Use plain text, JSON, CSV, HTML, or a table when the destination requires it.
- Preserve the same workflow across ChatGPT, Codex, Claude, Gemini, Copilot, Perplexity, local models, APIs, and automation platforms.

Read [references/platform-adapters.md](references/platform-adapters.md) only when installing, exporting, or adapting this skill for another AI platform.

## Gather the Brief

Use information already supplied before asking questions.

Identify.

- Source content or central idea.
- Business goal and funnel stage.
- Audience and awareness level.
- Platforms and requested formats.
- Brand voice, persona, and prohibited language.
- Offer and CTA.
- Publishing window and production limits.

Ask only for missing details that materially affect the result. If the user wants immediate output, state reasonable assumptions briefly and proceed.

## Build the Repurposing Strategy

1. Extract the thesis, supporting points, proof, stories, quotable lines, and intended action.
2. Separate evergreen material from time-sensitive material.
3. Select formats based on the goal, platform behavior, audience effort, available assets, and production capacity.
4. Give each derivative a distinct job or angle.
5. Map pieces into a useful sequence when the request covers several days or funnel stages.
6. Draft complete assets when requested.
7. Add production notes only when they help the user publish or delegate the work.

Do not create shallow copies with only different word counts.

## Match the Format to the Job

- Use carousels for structured education, frameworks, comparisons, and step sequences.
- Use short video for demonstrations, opinions, stories, transformations, and one clear lesson.
- Use threads for layered arguments, breakdowns, and commentary.
- Use email for context, trust, narrative, objection handling, and direct conversion.
- Use articles for search intent, durable education, and comprehensive explanations.
- Use quote cards and short posts only when the idea remains meaningful without missing context.
- Use stories, polls, questions, and prompts for participation, feedback, and audience research.

Treat posting-time, algorithm, and platform-feature claims as current information. Verify them when the user requests exact or current guidance.

## Preserve and Humanize the Voice

- Preserve the user's point of view, vocabulary, confidence level, and relationship with the audience.
- Remove generic openings, repeated conclusions, empty intensifiers, stiff transitions, and unnecessary jargon.
- Use natural sentence-length variation, concrete details, direct language, and context-specific observations.
- Distinguish polishing from impersonation.
- Use persona guidance as a voice target without claiming an identity or lived experience the source does not support.
- Support thought-leader, playful coach, corporate B2B, helpful mentor, founder-led, and bold trend-aware tones.

When a writing sample exists, extract.

- Sentence length and rhythm.
- Vocabulary level.
- Pronoun habits.
- Emotional register.
- Humor style.
- Words and constructions the person avoids.

## Create Engagement Ideas

Generate topics from.

- Customer questions and objections.
- Common mistakes and decisions.
- Myths and strong opinions.
- Behind-the-scenes processes.
- Case evidence and useful comparisons.
- Timely developments.
- Member or audience conversations.

For each idea, specify the audience tension, angle, recommended format, and conversation prompt. Favor relevance over bait.

Follow the table with every draft, script, slide, calendar entry, or template the user requested.

For calendars, include.

- Publication day or sequence.
- Platform and format.
- Topic or angle.
- Funnel stage or objective.
- Hook.
- CTA.
- Source asset.
- Production status or batching group when requested.

For content databases, provide fields that transfer cleanly into Notion, Airtable, or a spreadsheet. Do not claim to create or update an external system unless that capability is available and the user requests the action.

## Quality Check

Before delivering.

- Confirm every derivative traces back to the source.
- Confirm each format fits its platform and objective.
- Remove unsupported claims and invented details.
- Vary hooks and angles across the package.
- Make CTAs proportional to the funnel stage.
- Ensure humanization did not change facts or meaning.
- Confirm requested counts, lengths, and formats are complete.
